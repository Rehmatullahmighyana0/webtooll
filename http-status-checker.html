Understanding HTTP Response Statuses

      
Every web server returns a 3-digit numerical code informing the browser whether the request succeeded or failed. 200 OK indicates success, 301 Moved Permanently passes SEO link equity to new URLs, 404 Not Found warns of broken hyperlinks, and 500 Internal Server Error points to web server crashes.
