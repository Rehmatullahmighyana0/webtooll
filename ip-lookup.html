What is CIDR Subnetting?

Classless Inter-Domain Routing (CIDR) is an IP addressing scheme that allocates IP addresses and routes internet protocol packets more efficiently. A subnet prefix like /24 designates that the first 24 bits represent the network identity, leaving 8 bits (254 usable hosts) for individual network devices.
