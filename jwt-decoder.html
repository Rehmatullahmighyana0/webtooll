How JSON Web Tokens Work

      
A JSON Web Token (JWT) comprises three Base64URL-encoded strings separated by dots (.): the Header (specifying the signing algorithm like HS256 or RS256), the Payload (containing user IDs, roles, and standard timestamps like exp and iat), and the Signature.
