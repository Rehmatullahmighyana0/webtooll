What Are Cryptographic Hashes Used For?

A cryptographic hash function is a mathematical algorithm that maps data of arbitrary size to a bit array of a fixed size (a digest). Hashes are one-way functions: it is computationally impossible to invert or recreate the original input from the hash value.

Primary Use Cases

  • File Integrity Verification: Verify that downloaded software, ISO images, or zip archives have not been corrupted or tampered with by comparing checksums.
  • Password Storage: Web applications store salted SHA-256 or bcrypt hashes instead of plaintext passwords.
  • Git Version Control: Every commit and tree in Git is uniquely identified by its cryptographic SHA hash.
