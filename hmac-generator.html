What is an HMAC?

      
A Keyed-Hash Message Authentication Code (HMAC) is a specific type of message authentication code (MAC) involving a cryptographic hash function and a secret cryptographic key. It is commonly used to sign API requests (such as AWS, Stripe, and GitHub webhooks) to ensure both data integrity and message authenticity.
