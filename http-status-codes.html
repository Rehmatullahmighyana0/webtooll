Understanding HTTP Response Status Codes

HTTP status codes are 3-digit integers issued by a server in response to a client request. The first digit defines the response category: 1xx (Informational), 2xx (Success), 3xx (Redirection), 4xx (Client Error), and 5xx (Server Error).
