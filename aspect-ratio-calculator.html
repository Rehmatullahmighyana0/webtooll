How to Calculate Aspect Ratio Mathematically

An aspect ratio represents the proportional relationship between width and height. To scale dimensions without distortion: New Height = (Original Height / Original Width) × New Width, or New Width = (Original Width / Original Height) × New Height. This prevents stretching and letterboxing.
