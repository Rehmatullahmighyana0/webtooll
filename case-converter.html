Understanding Different Text Formats

Different industries and programming languages adhere to strict naming conventions and letter case formats:

  • Sentence case: The first letter of each sentence is capitalized, standard for natural writing and journalism.
  • Title Case: Capitalizes the principal words in a title, commonly used for blog headlines and books.
  • camelCase: Words are joined without spaces, starting with a lowercase letter and capitalizing each subsequent word (e.g., userId, fetchData in JavaScript).
  • PascalCase: Similar to camelCase but starting with an uppercase letter, common for class names (e.g., UserManager in Python and C#).
  • snake_case: All words in lowercase separated by an underscore, common in Python and database column names (e.g., first_name).
  • kebab-case: Words separated by hyphens, common in URLs and CSS class names (e.g., hero-title-section).
