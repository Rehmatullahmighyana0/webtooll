Understanding Number Radix Systems & Bitwise Math

Computers fundamentally process information as binary transistors (0 and 1). Hexadecimal (base 16) is human shorthand for bytes, grouping 4 bits into a single character (0-9, A-F). Octal (base 8) groups 3 bits and is traditionally used for Unix file permissions (e.g. chmod 755). Bitwise logic operations operate directly on individual bit positions rather than numerical values.
